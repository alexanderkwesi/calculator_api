# Calculator API

A mixed frontend/backend calculator project that demonstrates API-style calculation logic, frontend presentation and deployment configuration.

## Why I Built It

I built this project to practise routing user input through backend logic and returning predictable calculation results, while also experimenting with frontend presentation and deployment files.

## Features

- Backend folder for calculation/API logic
- HTML/CSS frontend
- Node package tooling
- Render deployment configuration
- Example assets and screenshots

## Tech Stack

- JavaScript / Node
- HTML
- CSS
- Backend API structure
- Render

## Project Structure

```text
backend/        Backend/API logic
build/          Build output
index.html      Frontend entry point
index.css       Frontend styles
render.yaml     Deployment configuration
package.json
README.md
```

## Getting Started

Install dependencies:

```bash
npm install
```

Run the project using the scripts in `package.json`.

## What This Shows

This project demonstrates backend calculation logic, API-style thinking, deployment awareness and frontend integration.
